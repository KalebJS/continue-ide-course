# Welcome & Setup

Welcome to the **VS Code & Continue** training course! This course is designed for project managers who want to use VS Code as a text editor and the Continue extension to work with AI agents — **no programming experience required**.

By the end of this course, you will be able to:

- Navigate VS Code confidently
- Create, edit, and manage text files
- Write formatted documents using Markdown
- Use the Continue extension to prompt AI assistants
- Reference files in your workspace when asking AI for help

## Step 1: Install Visual Studio Code

VS Code is a free, powerful text editor made by Microsoft. It works on Windows, Mac, and Linux.

1. Go to [https://code.visualstudio.com](https://code.visualstudio.com)
2. Click the **Download** button for your operating system (Windows, macOS, or Linux)
3. Run the installer and follow the default options

![VS Code download page](/images/01-vscode-download.png)

> **Tip:** On macOS, drag the VS Code app into your Applications folder after downloading. On Windows, the installer handles everything.

- [ ] Download and install VS Code on your computer

## Step 2: Open VS Code for the First Time

Once VS Code is installed, open it. You'll see a welcome screen. Take a moment to notice:

- The **Activity Bar** on the far left (icons for files, search, extensions, etc.)
- The **Editor** area in the center (where you'll write and edit text)
- The **Terminal** at the bottom (we won't use this much in this course)

![VS Code first launch](/images/01-vscode-first-open.png)

- [ ] Open VS Code and identify the Activity Bar, the Editor, and the Terminal panel

## Step 3: Install the Continue Extension

Continue is the AI assistant that lives inside VS Code. It lets you chat with an AI, ask it to edit your files, and reference documents in your project.

1. Open VS Code
2. Click the **Extensions** icon in the Activity Bar (it looks like four squares)
3. In the search box, type `Continue`
4. Look for the extension published by **Continue** (it has the Continue logo)
5. Click **Install**

Once installed, you'll see a new **Continue** icon in your Activity Bar. Clicking it opens the AI chat panel on the right side of your screen.

![Continue extension in the VS Code Marketplace](/images/01-install-continue.gif)

- [ ] Install the Continue extension from the VS Code Marketplace

---

## Step 4: Configure Continue

After installing Continue, it will guide you through setup. Here's what to do:

1. Click the **Continue** icon in the Activity Bar
2. Continue will ask you to choose an AI model provider. Select the one your organization uses (for example, OpenAI, Anthropic, or a local model)
3. If prompted, enter your API key or sign in with your organization's credentials

![Continue model provider selection screen](/images/01-continue-setup-provider.png)

> **Note:** Your IT team may have already configured this. If you're unsure, ask your manager or IT department which provider to select.

- [ ] Complete the Continue setup by selecting your AI model provider

## Step 5: Download the Practice Project

Throughout this course, you'll work with a fictional project called **Project Phoenix** — a company website redesign. This practice workspace contains realistic documents like meeting notes, requirements, and stakeholder lists.

1. Click the **Download Practice Files** button in the sidebar, or use this link: [Download Project Phoenix](/api/download-workspace)
2. Save the `Project-Phoenix.zip` file to your computer
3. Extract/unzip the folder
4. In VS Code, go to **File > Open Folder...** and select the `Project-Phoenix` folder
5. Click **Yes, I trust the authors** when prompted

You should now see the project files in the Explorer panel on the left side of VS Code.

![Opening the Project Phoenix folder in VS Code](/images/01-open-project-phoenix.gif)

- [ ] Download, extract, and open the Project Phoenix folder in VS Code
